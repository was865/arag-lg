# 014 設定パネル — 要件

旧版の設定モーダルのうち、見た目と回答の調整を新版に移す。アカウント（表示名・パスワード・端末）は 006 で作った内容をそのまま同じパネルのタブにする。

- R1 **入口。** サイドバーの利用者メニュー「設定」と ⌘,（Windows は Ctrl+,）で開く。タブは「外観」「回答」「アカウント」。Esc・外側クリックで閉じる。375px では下から出るシートにし、タブは上に横並び。
- R2 **外観。** テーマ（ライト・ダーク）、アクセント色（4 色）、表示密度（ゆったり・コンパクト）、引用の表示（番号・チップ・ピル）、ツールの表示（カード・タイムライン・ログ）、推論の過程を表示。変えるとすぐ反映し、この端末に保存する（従来の tweaks）。
- R3 **回答。** 検索で回答に渡す資料の数（top_k 1〜20）、1 文書から使う上限（per_document 0〜20、0 は無制限）、候補の数（candidate_k 1〜50、資料の数以上）、最大ステップ数（5〜20）、再検索の回数（0〜2）、出典を必ず付ける、分からないときはそう答える。詳細（同時に実行する検索の数 1〜8、関連とみなすしきい値 0〜1）は折りたたむ。範囲は API の AgentCfg.clamped と同じ。
- R4 **送り方。** 回答の設定はこの端末に保存し、質問ごとに `agent_cfg` として送る。既定から変えた項目だけを送り、何も変えていなければ送らない（サーバの既定が変わったらそれに従う）。「既定に戻す」で全部戻す。
- R5 **見える化。** 回答の設定を既定から変えているときは、タブ名に印を付け、パネル上部に「既定から n 項目を変えています」と出す。
- R6 根拠検証（verify）は B6 が実装されるまで出さない。
