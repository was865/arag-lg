# 008 スレッドの共有（P4）— 要件

旧版の `/s/<token>`（スレッドの共有リンク）を移す。完了基準: **スレッドの持ち主が公開範囲を選ぶとリンクが出て、範囲に合う人だけがそのリンクで会話を読める**。

## 1. 公開範囲

- R1. スレッドの公開範囲は `private`（自分のみ・既定）・`org`（ログインしている利用者）・`public`（リンクを知っている人。ログイン不要）。
- R2. 持ち主だけが変えられる。`org`・`public` にしたとき、まだ無ければ推測できないトークン（22 文字以上・128 bit 以上）を発行する。`private` に戻してもトークンは保つ（再公開で同じリンク）。
- R3. スレッドの一覧・詳細に `visibility` と `share_token` を含める（持ち主にだけ見える）。

## 2. 共有ページ

- R4. `GET /v1/shared/{token}` はログインの有無を問わず呼べる。`private`・存在しないトークンは同じ 404（存在を明かさない）。`org` を未ログインで開くと 401。
- R5. 返すのは表示に要る最小限: タイトル・公開範囲・各ターンの質問・回答・出典（番号と文書名）・日時。ステップ・章本文・文書 ID・利用者 ID・トークン数は返さない。
- R6. `/s/<token>` はログインなしで開ける画面。回答は Markdown で描き、引用番号の下に出典の文書名を並べる。未ログインで `org` のときはログインへ誘導する（戻り先はこのページ）。検索エンジンに索引させない。

## 3. 画面

- R7. チャットのヘッダに「共有」ボタン。ダイアログで公開範囲を選び、リンクをコピーできる。`private` ではリンクを出さない。変更に失敗したら元に戻して知らせる。

## 4. 監査

- R8. 公開範囲の変更を監査ログに残す（`thread.share`、範囲を detail に）。
