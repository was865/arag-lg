## 実装メモ

- トークンは `secrets.token_urlsafe(16)`（22 文字・128 bit）。32 文字を超えるトークンは DB を引かずに 404。
- 認証は任意の `OptionalPrincipal`（資格情報が無い・不正なら None）。共有ページはサーバで API を呼び、セッションがあれば JWT を付ける（`serverApiHeaders`）。
- C1: org（ログイン中は表示・未ログインはログイン誘導と API 401）、public（未ログインで本文と出典名）、private に戻すと「見つかりません」、noindex、モバイルのダイアログをブラウザで確認。
- 既知: 同じ文書の別の章を 2 つ引くと、出典に同じ文書名が 2 行並ぶ（番号は別）。
