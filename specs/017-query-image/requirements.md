# 017 質問に画像を添えて尋ねる — 要件

利用者が質問に画像（設備の写真・画面のスクリーンショット・図など）を 1 枚添えて尋ねられるようにする。
画像は図の説明用モデル（`ARAG_VLM_MODEL`、現在は GPU 機の Qwen3-VL）が文章にし、その文章を質問に添えて今までどおり検索・回答する（方式 A）。
回答モデルは画像を見ないので、UI で選ぶモデル（Qwen3-8B・DeepSeek など）に関係なく使える。

- R1 **添付。** 入力欄で画像を 1 枚添えられる（ボタンで選ぶ・貼り付け・ドラッグ＆ドロップ）。送る前に縮小表示し、外せる。
  形式は JPEG・PNG・WebP・GIF（最初のフレーム）。ブラウザで長辺 1600px 以内に縮めてから送る。
- R2 **受け付け。** API は画像を検証し（形式・大きさ・壊れていないか）、長辺 `ARAG_QUERY_IMAGE_MAX_PX`（既定 1280）以内の JPEG に変換して保存する。
  変換で位置情報などのメタデータは消える。上限（既定 8MB）を超える・画像でない・壊れているときは 422 で理由を返す。
- R3 **未設定のとき。** 図の説明用モデルが設定されていなければ、添付ボタンを出さず、API も 422（`image_unsupported`）で断る。
- R4 **読み取り。** 回答の前に、図の説明用モデルが質問を踏まえて画像の内容（写っている物・文字・型番・表示・数値）を書き出す。
  これを「画像を読み取る」ステップとして進行表示に出し、結果の文章も見られる。
- R5 **回答。** 読み取った文章を質問に添えてエージェントに渡す。検索語の書き換え・続きの質問でもその内容を踏まえる。
  読み取りに失敗したときは回答を止めず、画像を読めなかったことを添えて質問の文章だけで答える。
- R6 **履歴。** 質問の吹き出しに添付画像の縮小表示を出し、押すと大きく見られる。スレッドを開き直しても出る。
  画像はそのスレッドの持ち主だけが見られる。共有ページには画像を出さず「画像付きの質問」とだけ示す。
- R7 **文字なしの送信。** 画像だけで送ったときは「この画像について関連資料を調べてください」を質問文とする。
- R8 **片付け。** スレッドを削除したら、その中の質問画像も消す。

## 対象外（今回はしない）

- 回答モデルに画像をそのまま渡す（方式 B）。画像を読めるモデルを選んだときの強化として後で行う。
- 画像どうしの類似検索（画像の埋め込み）。
- 1 回に複数枚。

補足: 再生成・質問の編集（分岐）では、元のターンの画像をブラウザが読み直して送り直す（読み取りもやり直す）。
