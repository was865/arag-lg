# 007 文書ビューア（P4）— 要件

`docs/handoff.md` 第 3 節 P4 の「文書プレビュー」。完了基準: **文書ライブラリから文書を開くと、解析結果（章ごとの整形表示・目次）と原本を同じ画面で読め、その文書に絞って質問できる**。

## 1. 開く

- R1. ライブラリの文書名をクリックすると文書ビューアが開く（`/library/<kb>/doc/<id>` ではなくライブラリの上に重ねる画面。URL は `?doc=<id>` を持たず、閉じると一覧に戻る。戻るボタンでも閉じる）。
- R2. ヘッダに文書名・KB・状態・ページ数・チャンク数を出し、「原本を開く」「ダウンロード」「この文書に質問」を置く。Esc で閉じる。

## 2. 整形表示

- R3. 解析済み（ready）の文書は、章（セクション）を順に整形表示する。表は表として、数式・Mermaid・画像も描画する（チャットの出典パネルと同じ規則）。
- R4. 章は 50 件ずつ読み込み、末尾に近づいたら続きを読む。
- R5. 目次（見出しの階層・ページ）を左に出し、クリックするとその章へ移る。読んでいる章を目次で示す。モバイルでは目次をボタンで開閉する。
- R6. 画像の `assets/<name>` は `/api/v1/documents/<id>/assets/<name>` に解決する。
- R7. 解析中・失敗の文書では整形表示の代わりに状態を出し、原本タブは使える。

## 3. 原本

- R8. 原本タブ: PDF と画像はブラウザで表示する。テキスト系（txt・md・csv・json・html は文字列として）は本文をそのまま表示する（1 MB まで。超えたら先頭だけと注記）。それ以外はダウンロードを案内する。

## 4. 質問

- R9. 「この文書に質問」でチャットに戻り、検索範囲をその文書に絞った新しいスレッドを始める（`document_ids`）。検索範囲の表示は文書名。

## 5. API

- R10. `GET /v1/documents/{id}/sections?offset&limit`（limit ≤ 100）は章を順に本文つきで返す。権限は他の文書 API と同じ。
