# 009 文書ライブラリの一括操作（P4）— 要件

完了基準: **ライブラリで複数の文書を選び、まとめてフォルダへ移す・ごみ箱へ移すことができる**。API（`bulk-move`・`bulk-delete`、1 回 500 件・全件書ける場合のみ成功）は既存。

- R1. ツールバーの「選択」で選択モードに入る。デスクトップでは行のアイコンにカーソルを当てるとチェックボックスが出て、押すと選択モードに入る。
- R2. 選択モードでは行のクリックで選択を切り替える（文書ビューアは開かない）。Shift+クリックで前に選んだ行からの範囲を選ぶ。
- R3. 下部の操作バーに件数・「すべて選択」（読み込み済みの文書）・「移動」・「ごみ箱へ」・「解除」。Esc で解除。
- R4. 「移動」は KB を開いていて、その KB に書けるときだけ。移動先はフォルダの選択ダイアログ。
- R5. 「ごみ箱へ」は確認してから。選んだ文書がすべて書けるときだけ押せる。500 件を超えたら分けて送る。
- R6. KB・フォルダ・絞り込みを変えたら選択を解く。操作が終わったら選択を解いて一覧を取り直す。
