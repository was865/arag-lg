# 009 文書ライブラリの一括操作 — タスク

- [x] B1 選択の純粋関数とテスト — R2, R5
- [x] B2 選択モード・チェックボックス・操作バー — R1〜R6
- [x] C1 ブラウザで確認（範囲選択・移動・ごみ箱へ・モバイル）

## 実装メモ

- C1: デスクトップで行アイコンのチェック → Shift+クリックで範囲選択、3 件をフォルダへ移動、フォルダ内で「すべて選択」→ 確認 → ごみ箱へ。モバイルは「選択」ボタンから行のタップで切り替え、すべての文書の表示では「移動」が押せないことを確認。
- 確認用に個人ナレッジベースへ「一括A〜C.txt」と「一括テスト」フォルダを作った（文書はごみ箱、フォルダは空のまま）。
