# 015 ヘルプと初回ガイド — 要件

旧版のヘルプ（左のナビ・概要・基本の流れ・主要機能・ショートカット・コツ）と初回のスポットライトツアーを、見た目と仕組みはそのまま移植する。文言は新版に実在する機能だけに直す（旧版には質問へのファイル添付・⌘K・C/R/1〜9 など、新版に無い機能やキーが含まれる）。

- R1 **入口。** 利用者メニュー「ヘルプ」と `?`（入力欄にフォーカスが無いとき）で開く。Esc・外側クリックで閉じる。375px では下から出るシート。
- R2 **概要・基本の流れ・主な機能。** 概要には件数（検索できる文書・ナレッジベース・未完了）と各項目への入口を置く。 質問 → 検索の経過 → 出典付きの回答 の流れと、主な機能（検索の範囲・文書の追加〈フォルダごと可〉・出典パネル・再生成と質問の編集・評価・共有と .md・ごみ箱・設定）を短く説明する。
- R3 **ショートカット。** 実際に効くキーだけを、キー判定と同じ定義から一覧にする（表記のずれを防ぐ）。Mac 以外は ⌘ を Ctrl と読み替える注記を付ける。
- R4 **コツ。** 質問の書き方（条件を具体的に・複合質問は分ける・社内の略語は展開）と注意（範囲を絞る・出典を確かめる・「リンクを知っている人」の共有範囲）。
- R5 **初回ガイド。** 初めてログインした利用者に、画面の実物（ナレッジベース・検索の範囲・入力欄・利用者メニュー）を順にスポットライトで示す 4 ステップの案内を 1 回だけ出す。対象が見えないとき（375px で閉じたサイドバー等）はステップを飛ばさず、スポットライト無しのカードで説明する。スキップ・完了で以後出さない（この端末に利用者ごとに記録）。ヘルプから「もう一度見る」で再生できる。
