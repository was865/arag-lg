# 025 外観 v2 と動き

> 状態: **承認済み（2026-11-11）**。提案ページの案 B「外観 v2 + 動き」。
> 提案: https://claude.ai/artifact/1E8C4rPSuDgxQ6LVUMj4G3 （十の見本と参照ライブラリの許諾確認を含む）

## 1. 背景

共通部品（Dialog・Button・Menu・Popover・Input・Badge）と文字・角丸の段階は 001〜024 の後の UI 整理でそろった。
一方で画面はほぼ静止している: CSS の短いキーフレームが 9 つだけで、閉じるときの動きが無く、画面の切り替えに
つながりが無く、回答は数語ずつ飛び出す。全面的な作り直しは機能の再検証（24 仕様）が重いので行わず、
共通部品と会話の部品の層で外観と動きを作り直す。

## 2. 動きの約束（全段階に共通）

- R1 時間は 3 段だけ: 速い 120ms（ホバー・押下）、中 200ms（メニュー・カード）、遅い 320ms（ダイアログ・画面の切り替え）。
- R2 曲線は 2 本: 出るときは少し跳ねるばね、消えるときは素早い ease-in。消える方を出る方より約 3 分の 1 短くする。
- R3 読んでいるもの（回答本文・表・入力中の文字）は位置や大きさを動かさず、淡くするだけ。
- R4 飾りの動きは 1 画面に 1 つまで（首ページの空の状態とログイン画面の光だけ）。
- R5 OS の「視差効果を減らす」が有効なら、すべての動きを即時の切り替えにする（CSS も Motion も）。
- R6 動かすのは transform と opacity だけ。長い一覧は最初の画面分だけ動かす。
- R7 商用利用に制限のある依存は入れない。新しい実行時依存は `motion`（MIT）だけ。

## 3. 段階

### 第 1 段階: 動きの土台

- R10 R1・R2 の値を CSS 変数と TS の定数の両方に置き、どちらも同じ値にする（テストで確かめる）。
- R11 ダイアログ・メニュー・ポップオーバーに閉じるときの動きを付ける。メニューとポップオーバーは開いた位置（ボタンの角）から広がる。狭い画面のダイアログ（シート）は下から上がり、下へ下がる。
- R12 セグメントの選択中の背景が、新しい選択肢へ滑って移る。
- R13 通知（トースト）は重なった束になり、古いものは縮んで後ろへ下がる。4 件目以降は隠す。ホバー（またはフォーカス）で束を広げて全部見せる。閉じると残りが詰める。
- R14 ボタンは押したときにわずかに縮む（`disabled` では縮まない）。
- R15 `/dev/ui` に動きの見本を足す。

### 第 2 段階: 会話（別ブランチ）

- R20 回答の文字はぼかしから淡く現れる。カーソルは点滅でなく呼吸する。
- R21 エージェント実行は時系列で 1 行ずつ現れ、実行中の行は光が流れ、完了で勾が描かれる。経過時間を出す。
- R22 本文の引用番号にホバー・フォーカスすると出典カード（文書名・頁・該当文の強調）が番号の位置から現れる。
- R23 下へ戻るボタン、思考の折りたたみ（「思考 5 秒」）。

### 第 3 段階: 画面の切り替えと一覧（別ブランチ）

- R30 React の `<ViewTransition>` で、会話の切り替え・資料庫から文書の表示・管理画面のタブを動かす。未対応のブラウザでは即時に切り替える。
- R31 一覧の行は順に現れる（最初の画面分だけ）。概要の数字は 0 から数え上げる（最初の表示だけ）。
- R32 読み込み中は回転でなく骨組み（スケルトン）を出す。ファイルを画面に持ち込んだら画面全体で受け止める。

### 第 4 段階: 外観 v2（別ブランチ）

- R40 サイドバーを半透明にして背景をぼかす。カードの影を 3 段の奥行きで使い分ける。
- R41 首ページと登録画面に、ブランド印の後ろでゆっくり動く光を置く。空の状態に挿絵を付ける。
- R42 ⌘K のコマンドパレット（文書を探す・会話へ移る・操作を実行する）。
- R43 配色（暖色を残すか）はこの段階の始めに改めて決める。

## 4. 範囲外

- 部品の構造や API の作り直し、状態管理の変更。
- 3D 傾き・磁石ボタン・粒子のような目立つだけの効果。
