# 030 解析の点検（Docling の解析結果を確かめ、原件と突き合わせる） — 要件

状態: **着手**。main で進める（小さな変更を重ねる）。

## なぜやるか

- 回答が誤ったとき、原因が (a) Docling の抽出、(b) チャンク化、(c) 文脈付与、(d) 検索・回答のどれかを切り分けられない。今は `original.*`・`docling.json`・`rendered.md` を保存しているが、`rendered.md` 以外は画面からも API からも取れない。
- docling-serve の `partial_success` と `errors` は、失敗のときしか記録しない。降級して解析された文書を後から見分けられない。
- チャンクは `boxes`（頁・座標）を持つのに、原件の上で確かめる画面が無い。
- 抽出の異常（空の頁・文字化け・崩れた表・欠けた図）を、人が全頁を読まずに知る手段が無い。

## 1. 解析の記録（第 1 層）

- R1. 解析が終わるたび、システムは `parse_report.json` を原件と同じ場所（`contents/<hash>/`）に保存する。内容: 解析器の名前と版、docling-serve の `status`・`errors`・窓の数・所要時間・送ったオプション、全体の合計（頁・文・表・図・文字・チャンクの数）、頁ごとの数（項目・文字・表・図・チャンク）、警告の一覧。
- R2. docling-serve が `partial_success` を返したとき、またはエラーを含むとき、システムは入庫を止めず、警告（`docling_partial` / `docling_errors`）として記録する。
- R3. `GET /v1/documents/{id}/parse-report` は、読める文書の記録を返す（管理者以外にも可。内容に本文を含めない）。記録が無い古い文書は 404。
- R4. `GET /v1/documents/{id}/docling` は Docling の生の JSON を返す。**管理者（owner / admin）だけ**。画像の埋め込みは含まれない（`assets/` に出してある）。

## 2. 自動の体検（第 2 層。規則だけ、モデルは使わない）

- R5. 記録の作成時に次を検査し、警告（`code`・`severity`・頁・説明）として入れる:
  - `empty_page`（info）: 頁に文も表も図も無い。
  - `image_only_page`（warn）: 頁に図があるのに文がほぼ無い（OCR の失敗の疑い）。
  - `garbled_text`（warn）: 置換文字（U+FFFD）・制御文字の割合が高い。
  - `table_sparse`（warn）: 3 行以上の表で、空のセルが半分を超える。
  - `missing_asset`（warn）: 図の参照先が `assets/` に無い。
  - `bbox_out_of_page`（warn）: チャンクの枠が頁の大きさを大きく外れる。
  - `no_text`（warn）: 文書全体で文字が無い。
  - `chunk_page_gap`（info）: 文のある頁に、チャンクが 1 つも無い。
- R6. 文書の一覧・詳細は、警告（warn 以上）の件数を持つ（`parse_warnings`）。画面は件数があるとき札を出す。
- R7. 規則はすべて純関数で、小さな DoclingDocument のフィクスチャで試せる。
- R8. 既に入庫済みの文書には、`python -m arag.cli reparse-report` で、保存済みの `docling.json` から記録を作り直せる（Docling を呼び直さない。docling-serve 由来の項目は欠ける）。

## 3. 原件との対照（第 3 層）

- R9. 文書の画面に「対照」を足す。左に原件の頁（PDF）、右にその頁のチャンクを並べ、チャンクを選ぶと左の頁に `boxes` を枠で重ねる。左の枠を押すと対応するチャンクを選ぶ。座標の原点（`BOTTOMLEFT` / `TOPLEFT`）に従って向きを直す。
- R10. 選んだチャンクについて、Docling の抽出文（チャンクの文）・文脈・実際に埋め込みへ送った本文を並べて見せる。
- R11. PDF 以外の形式（xlsx・pptx・docx 等）は第 1 版では枠を重ねず、チャンクの一覧と 4 つの本文だけを出す。
- R12. 警告のある頁は、頁の一覧で札を出し、押すとその頁へ飛ぶ。
- R13. 回答の「詳細」の出典の札から、その文書の「対照」を、該当のチャンクを選んだ状態で開ける。

## 採らないもの

- Docling の再解析の画面ボタン（再索引は既存の CLI で足りる）。
- 解析結果の手直し（編集）。直すなら原件を直して入れ直す。
