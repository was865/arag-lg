# 011 監査ログ（P5）— 要件

`docs/handoff.md` P5 の「审计」。完了基準: **owner・admin が、誰がいつ何をしたか（文書・フォルダ・KB・共有・メンバー管理・質問）を絞り込んで見られる。記録は利用者が書き換えられない**。

- R1. `GET /v1/admin/audit` は owner・admin だけ（それ以外は 403）。新しい順に、操作者（ID・メール）・操作・対象・結果・IP・詳細を返す。50 件ずつのカーソル送り。
- R2. 絞り込み: 操作の種類（前方一致。例 `document.`）・操作者（ID かメールの部分一致）・期間（from・to）。
- R3. メンバー管理（010）の招待・役割の変更・停止・再開・再送も監査ログに残す。Web のサーバから `POST /v1/admin/audit` で書く。書ける操作は `member.*` だけで、操作者は JWT の利用者とする。
- R4. ブラウザから `/api/v1/admin/audit` に書き込むことはできない（中継が 403）。読み取りは中継を通す。
- R5. 画面 `/admin/audit`: 操作の種類の選択・操作者の検索・期間・「さらに読み込む」。操作名は日本語で見せる。メンバー画面と行き来できる。
