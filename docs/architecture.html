ARag 当前架构

应用跑在 Mac 上，模型跑在 GPU 机上，云端 API 作为可选项。下面先回答两个问题，再用三张图说明：各个组件在哪里、文档怎么入库、提问怎么得到回答。回答内部的流程（理解 → 检索 → 调查 → 确认 → 确定）不在这里手画，以从代码生成的 docs/agent-graph.md 为准。

提问时能在 UI 上切换本地和 API 吗？

能，每次提问都可以换。输入框旁的模型选择器列出模型目录里的模型（Gemma 4 12B 本地、DeepSeek 等），选中的模型随这次提问一起发给后端，同一个对话里也能中途换。

只换「写回答」的模型。检索（向量、重排序）和改写检索词的辅助模型由启动配置决定，不随选择器变化。没登记 key 或没有地址的模型会显示为不可用。

图片模型现在用在哪里？

入库和提问都用，而且和写回答是同一个模型。本地默认的 Gemma 4 12B 能看图：入库时为 Docling 抠出的每张图写一段文字说明，作为一个「图」小块和正文一起存进检索库。

提问时如果附了图片，先由同一模型把图片转成文字，附在问题后面再检索和回答（specs/017）。检索到的始终是文字。
